# База данных «Туризм»

Учебный проект базы данных для туристической компании.

## Описание

База данных предназначена для хранения информации:

- о клиентах;
- об отелях;
- о видах туристических туров;
- о бронированиях.

В проекте используются четыре таблицы:

- `clients` — справочник клиентов;
- `hotels` — справочник отелей;
- `tour_types` — справочник видов туров;
- `bookings` — таблица бронирований.

## Связи между таблицами

```text
bookings.client_id → clients.client_id
bookings.hotel_id → hotels.hotel_id
bookings.tour_type_id → tour_types.tour_type_id
